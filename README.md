# Houston Sector Radar

## Houston Hackathon 2026 Prototype

Houston Sector Radar is a limited workforce exploration prototype developed for the Houston Hackathon 2026.

## What Houston Sector Radar Does

Houston Sector Radar uses publicly available labor-market data to allow users to:

- View select Houston workforce and industry data
- Enter existing professional skills
- Explore potential connections between those skills and industries

This project is a limited prototype created specifically for demonstration purposes.

## Data

Houston Sector Radar uses publicly available data, including information from the U.S. Bureau of Labor Statistics (BLS).
